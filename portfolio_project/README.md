# Personal Portfolio Website (CSS Core) - Lab 2

This repository contains Lab Assignment 2 for Web Development I.

## Features Implemented
- Linked external stylesheet (`style.css`).
- Styled navigation bar with hover effects.
- Google Fonts (`Poppins`) integrated for custom typography.
- Box model applied for structure, borders, shadows, and margins.
- Custom styled skills table with alternating borders/colors.
- Styled form fields and buttons with hover state interactions.
- Positioned `Back to Top` button (`position: fixed`).
- Clean visual separators using styled `<hr>`.
